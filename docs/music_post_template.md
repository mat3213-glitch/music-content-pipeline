# Music Post Template

## Как заполнять

Скопируй этот шаблон, заполни поля и положи файл в нужную папку:

- `music post/моя музыка/новая/` - свои новые треки
- `music post/моя музыка/старая/` - свои старые треки
- `music post/не моя/` - чужие треки / референсы

Когда шаблон заполнен, локальный ingest-скрипт забирает его в работу.
